# Sana Liaqat — Product Manager Portfolio

A modern, production-ready Product Manager portfolio website for **Sana Liaqat**, built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

The portfolio demonstrates evidence-driven product thinking:
**Discovers problems → uses data → defines solutions → coordinates technical delivery → launches products → measures impact**

---

## Target Roles & Domains

- **Target Roles:** Product Manager • Technical Product Manager • FinTech Product Manager • Platform Product Manager • Product Operations Manager
- **Primary Domains:** FinTech • SaaS • eCommerce • Marketplaces • PropTech • AI Products

---

## Key Highlights & Product Deliverables

1. **Hero & Dynamic Product Pipeline**:
   - Status badge: *Product Manager • Open to Global Remote Opportunities*
   - Interactive 6-stage product delivery pipeline: `CUSTOMER → PRODUCT → DATA → DECISION → DELIVERY → IMPACT`
   - 4 impact metric cards: 7+ Years Experience, 50+ Product Initiatives, 33% Cancellation Reduction, E2E Discovery-to-Impact.

2. **Product Philosophy**:
   - *"I don't start with features. I start with the problem."*
   - 4 capability pillars: Discover, Define, Deliver, Optimize.

3. **Product Impact Scorecard**:
   - High-contrast oversized metric cards (50+ Initiatives, 33% Cancellation Reduction, 7+ Years Experience, Multi-Sided Marketplace Experience).

4. **Flagship Case Study**:
   - *"From Cancellation Data to Product Intervention"* — deep dive into how behavioral analysis in Mixpanel and New Relic log audits turned a cancellation leak into the high-retention **Edit Order** experience.
   - Side-by-side BEFORE vs. AFTER user journeys.
   - 33% reduction in post-order cancellations.

5. **6 Selected Product Initiatives & Modal Deep-Dive**:
   - **Project 01**: Cancellation Reduction & Edit Order (Product Discovery)
   - **Project 02**: Smiles × elGrocer SDK Integration (Platform / Embedded Commerce)

   - **Project 05**: Automated Order Lifecycle Escalation (State Machine & IVR/Slack Automation)

6. **Interactive Commerce Lifecycle Architecture**:
   - Interactive system graph: `CUSTOMER APP → CATALOGUE & CART → CHECKOUT → PAYMENTS → ORDER MANAGEMENT → RETAILER / PICKER → DRIVER → DELIVERY`.

8. **Layer-by-Layer Career Journey**:

9. **Toolbox (Zero Percentage Bars)**:

## Technical Stack

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS (Custom Charcoal & Electric Violet/Indigo palette)
- **Icons**: Lucide React
- **SEO**: Dynamic Metadata, OpenGraph, JSON-LD Schema (`Person`)

## Getting Started

```bash
# Navigate to the portfolio directory
cd /Users/sannayamughal/.gemini/antigravity/scratch/sana-liaqat-portfolio

# Install dependencies (already installed)
npm install

# Run the development server
npm run dev

# Or run the optimized production build
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) with your browser to view the portfolio.
